# Repositorio para la entrega de la tarea: "Uso y documentación de Makefiles"

En este repositorio se encuentra la reprouccion del ejercicio del repositorio ejemplo (Julia) con makefiles visto en clase el cual fue ejecutado y debidamente documentado mediante un reporte en un archivo **README** 

De igual manera, se encuentra el proyecto propio que hace uso de Makefile para su automatizacion, estandarizando asi la compilacion y ejecucion del codigo, evitando errores humanos en este proceso que puedan ocasionar complicaciones en compilacion o ejecucion, de esta forma asegurando un correcto funcionamiento. Dicho proyecto contiene su debida documentacion en un archivo **README** para su correcto entendimiento.

Ademas se encuentra un archivo .gitignore que evita asi la carga de archivos producto de compilacion o ejecucion.
